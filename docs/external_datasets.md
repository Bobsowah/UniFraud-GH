## How these map to the paper
* A second **real-derived** sector pair (BAF; Medicare provider data) would reduce reliance on simulators.
* UCI credit-default and AML/Elliptic serve as **negative-transfer controls** (related but different tasks).
* The two small downloaded CSVs are suitable for **pipeline unit/smoke tests only**.

## Access needed
Allow these hosts under the environment's Network access settings (Allowed domains) if you want the session to
fetch them: `archive.ics.uci.edu`, `www.kaggle.com`, `api.kaggle.com`, `data.mendeley.com`, `zenodo.org`,
`www.openml.org`, `huggingface.co`, `data.cms.gov`. Kaggle also needs an API token supplied as an
environment secret (never paste it in chat).
